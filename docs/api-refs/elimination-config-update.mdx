# Update Elimination Config

```bash
curl --location "$BASE_URL/rule/update" \
  --header "$AUTH_HEADER" \
  --header "Content-Type: application/json" \
  --data '{
    "merchant_id": "merchant_demo",
    "config": {
      "type": "elimination",
      "data": {
        "threshold": 0.15
      }
    }
  }'
```

```json
{
  "message": "Elimination Configuration updated successfully",
  "merchant_id": "merchant_demo",
  "config": { "type": "elimination", "data": { "threshold": 0.15, "txnLatency": null } }
}
```
