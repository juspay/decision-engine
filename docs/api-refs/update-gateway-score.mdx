# Update Gateway Score

Call this after non-debit runtime payments so SR data stays current. Do not call it for `NTW_BASED_ROUTING` debit runs where `decided_gateway` is not the selected network.

## Request

```bash
curl --location "$BASE_URL/update-gateway-score" \
  --header "$AUTH_HEADER" \
  --header "Content-Type: application/json" \
  --data '{
    "merchantId": "merchant_demo",
    "gateway": "stripe",
    "gatewayReferenceId": null,
    "status": "CHARGED",
    "paymentId": "sr_001",
    "enforceDynamicRoutingFailure": null,
    "customerId": "cust_123",
    "paymentMethod": "INTERAC",
    "paymentMethodType": "RTP"
  }'
```

`customerId`, `paymentMethod`, and `paymentMethodType` are optional and feed sticky-routing
success counts (per-merchant flag `sticky_routing_enabled`). When absent they are recovered
from the decide-time snapshot, which expires 30 minutes after the decide call — send them
explicitly if your success webhooks can arrive later than that. Send the same values as the
decide call's `paymentInfo`; they are matched case-insensitively. For UPI, send the payment
source object (e.g. `UPI_COLLECT`) as `paymentMethod`, matching what the engine keys by.

## Response

```text
Success
```
