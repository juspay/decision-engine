# Update Gateway Score

Call this after non-debit runtime payments so SR data stays current. Do not call it for `NTW_BASED_ROUTING` debit runs where `decided_gateway` is not the selected network.

## Request

```bash
curl --location "$BASE_URL/update-gateway-score" \
  --header "$AUTH_HEADER" \
  --header "Content-Type: application/json" \
  --data '{
    "merchantId": "merchant_demo",
    "gateway": "stripe",
    "gatewayReferenceId": null,
    "status": "CHARGED",
    "paymentId": "sr_001",
    "enforceDynamicRoutingFailure": null
  }'
```

To have the update checked against the payment's `/decide` decision, name the connector with
`attemptedConnector`, copied from the `/decide` response, instead of `gateway`:

```bash
curl --location "$BASE_URL/update-gateway-score" \
  --header "$AUTH_HEADER" \
  --header "Content-Type: application/json" \
  --data '{
    "merchantId": "merchant_demo",
    "attemptedConnector": { "connector": "stripe", "merchant_connector_id": "mca_stripe" },
    "status": "CHARGED",
    "paymentId": "sr_001"
  }'
```

A connector the payment's stored decision did not offer is refused with `422` `CONNECTOR_NOT_OFFERED`.
A payment without a stored decision is answered as a `gateway` update would be.

## Response

```text
Success
```
