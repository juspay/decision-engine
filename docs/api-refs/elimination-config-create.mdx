# Create Elimination Config

```bash
curl --location "$BASE_URL/rule/create" \
  --header "$AUTH_HEADER" \
  --header "Content-Type: application/json" \
  --data '{
    "merchant_id": "merchant_demo",
    "config": {
      "type": "elimination",
      "data": {
        "threshold": 0.2
      }
    }
  }'
```

`threshold` is the SR score (0–1) below which a gateway is eliminated. An optional `txnLatency` object (`{ "gatewayLatency": <ms> }`) adds a hard latency cut-off.

```json
{
  "message": "Elimination Configuration created successfully",
  "merchant_id": "merchant_demo",
  "config": { "type": "elimination", "data": { "threshold": 0.2, "txnLatency": null } }
}
```
